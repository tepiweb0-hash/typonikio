KIOCREATES TYPOGRAPHY STUDIO V1.4 — PHOTO COMPOSITION PATCH

Replace these files in your existing Typography Studio project:
- components/TypographyStudio.js
- app/globals.css

- Multiple picture uploads / layers
- Photo background with Full / Top / Bottom / Left / Right placement
- Photo background opacity, blur, and blend modes
- Blend modes including Multiply, Screen, Overlay, Soft Light, Hard Light, Darken, Lighten, Color Burn, Color Dodge, Difference
- Partial background color blocks (+ Block)
- Attachable photo-frame slots inside templates
- Digital Poetry section (12 templates)
- Photo Frames section (12 templates)
- Existing Photo templates upgraded to attachable photo slots
- Frame photo replace, clear, fit, zoom, X/Y positioning, blend mode
- Template layout locked by default
- Template Lock / Unlock control
- Per-layer Lock / Unlock control
- Template photos can be replaced while the template layout stays locked
- Template frame photos are preserved when editing the quote
- T-Shirt category removed (references were treated as visual inspiration only)
- Mobile responsive behavior retained
